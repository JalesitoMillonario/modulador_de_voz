👋 ¡Hola! Tu app está lista. Aquí está cómo instalarla en tu iPhone:

═══════════════════════════════════════════════════════════════

📋 PASOS RÁPIDOS:

1️⃣  EN TU MAC - Abre Terminal y ejecuta:

    cd modulador_de_voz
    npm install
    npm run dev

2️⃣  OBTÉN TU IP - En otra terminal (o pestaña):

    npm run ip

    Te mostrará algo como:
    📱 Tu IP local:
       http://192.168.1.5:3000

3️⃣  EN TU IPHONE - Abre Safari:

    • Escribe la URL que obtuviste (ej: http://192.168.1.5:3000)
    • Acepta el permiso del micrófono
    • Toca el botón Compartir (↑)
    • Selecciona "Agregar a pantalla de inicio"
    • Toca "Agregar"

4️⃣  ¡LISTO! Ya está instalada en tu iPhone como app nativa
